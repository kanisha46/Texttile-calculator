# 🧵 Textile Yarn Calculator

A simple and interactive web application to calculate **warp and weft yarn consumption, cost, and percentage distribution**.

🔗 **Live Demo:**
https://kanisha46.github.io/Texttile-calculator/

---

## 📌 Features

* ✅ Add multiple **Warp** and **Weft** entries
* ✅ Calculate **Yarn Weight (kg)** automatically
* ✅ Calculate **Cost (₹)** based on rate
* ✅ View **Subtotal & Grand Total**
* ✅ See **Percentage Contribution (Warp vs Weft)**
* ✅ Clean and responsive UI
* 🔒 Simple password protection

---

## 🧮 Formula Used

### Warp:

Weight (kg) =

```
(Denier × Taar × Factor) / 9,000,000
```

### Weft:

Weight (kg) =

```
(Denier × Peek × Panna × Factor) / 9,000,000
```

### Cost:

```
Cost = Weight × Yarn Rate
```

## 🌐 Deployment

This project is deployed using **GitHub Pages**.

To deploy:

1. Upload code to GitHub
2. Go to **Settings → Pages**
3. Select branch (`main` or `master`)
4. Your site will be live 🎉
